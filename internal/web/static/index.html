Multi-Source Repo Sync

Carregando…

Nada é mesclado, apagado ou sobrescrito por aqui. Sincronizar cria um branch novo e abre uma PR no repositório de destino, depois que você digitar a confirmação exata. “Analisar” baixa o histórico para checar conflitos e pode levar um minuto.

Empurrar uma branch para as outras cópias

Cria a mesma branch nas outras organizações que têm o serviço e abre uma PR para o main de cada uma. Serve para levar um trabalho feito num lugar para os demais. Branch que já existe lá com outro conteúdo não é tocada.
